## Corporate Hub (PWA)

Каркас корпоративного PWA (HTML5 + JS + TailwindCSS) со структурой разделов по `funcProject.txt`.

### Запуск локально

Откройте проект через любой статический сервер (нужно, чтобы корректно работали ES-модули и service worker).

Пример (если установлен Node.js):

```bash
npx serve .
```

И откройте адрес, который покажет команда (обычно `http://localhost:3000`).
